# Record Brief

Use for concise owner, account, or opportunity briefs: current state, biggest changes, risks, and next follow-up.

## Flow

1. Resolve the record first.
2. Start with the CRM summary when that record type supports summaries.
3. Add opportunity artifacts only if you need action priority, next steps, or close-date signals.
4. Add user notes or facts only if the summary is not enough.
5. Add communications only for the few records where the answer still lacks evidence.

## Good Inputs

- `get_crm_summary_sections`
- `get_crm_summary_progression`
- `get_pipeline_suggestions`
- `query_crm_data`
