# Meeting Review

Use for meeting prep, post-meeting review, or meeting eval.

## Flow

1. If the meeting is not already known, discover it with `list_appointments` filters or appointment search.
2. Start with meeting artifacts.
3. Use `prep` for upcoming meetings and `summary` or `eval` for meetings that already happened.
4. Read transcript or notes only if the artifact is missing or too shallow for the question.

## Good Inputs

- `list_appointments`
- `get_appointment_artifacts`
- `get_meeting_transcript_or_notes`

## Notes

- Keep appointment filters tight; broad org-wide meeting reads are usually wrong.
- For artifact semantics, read `../revenue-grid-platform/SKILL.md`.
