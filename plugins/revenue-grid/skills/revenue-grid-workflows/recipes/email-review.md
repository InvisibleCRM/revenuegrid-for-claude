# Email Review

Use for email activity around a record, contact, or theme.

## Flow

1. If you already know the record, filter emails by CRM links or recipients.
2. If you only know a free-text theme, use `list_emails` or `list_appointments` with `search`, then narrow with structured filters when possible.
3. Triage with snippets first.
4. Re-run with full bodies only for the small set of emails that matter.
5. Bring in meetings only when the answer is clearly cross-channel.

## Good Inputs

- `list_emails`
- `list_appointments`

## Notes

- Prefer record-linked filters over broad tenant-wide searches.
- Use bodies only for narrowed follow-up reads.
